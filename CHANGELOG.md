# Changelog

All notable changes to OpenCode Usage Tracking are documented here.

## [1.0.0] — 2025-01-14

### Added
- Overview dashboard with KPI cards, activity charts, token flow, cache rate
- Sessions page with search, project filters, and range selection
- Session detail view with full message timeline, tool calls, and files changed
- Tool calls page with filtering and pagination
- Projects, Models, Files, Todos, and Agents pages
- Dark/light theme support (removed in later versions)
- Hourly heatmap and weekday radar charts
- Token breakdown visualization per session
- Auto-launch setup script for OpenCode integration
